# MyOS

MyOS is a hobby operating system being developed from scratch.

## Project Information

- Version: 0.1.0
- Architecture: x86_64
- Language: C
- Assembly: NASM
- Bootloader: Limine
- Compiler: LLVM Clang
- Linker: LLD
- Emulator: QEMU
